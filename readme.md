# QUANTA — Atomic Physics Laboratory

QUANTA is an interactive browser-based physics lab for exploring atomic, quantum, thermodynamic, fluid, electromagnetic, and optics concepts through visual simulations. It is built with React, Vite, Three.js, React Three Fiber, and Recharts.

## Features

- **13 guided lab modules** — ten physics labs (atomic structure, hydrogen spectra, photoelectric emission, radioactive decay, particle collisions, thermodynamics, fluid dynamics, quantum physics, electromagnetism, optics) and three mathematics labs (real analysis, complex analysis, vector spaces).
- **Interactive 3D and chart-based visualizations** using Three.js, React Three Fiber, and Recharts.
- **Built-in theory drawer** that summarizes the governing equations and concepts for each module.
- **Session progress tracking** as learners visit each lab.
- **Notebook export** for saving observations and generated session reports.
- **Frosted-white glass UI** — off-white canvas, blurred pastel light, translucent cards and slate text for low eye strain; detector screens stay dark so coloured hits remain readable. Layout is responsive down to phone width.
- **Fixed-format result export** — one click to a spreadsheet (.csv) or a printable report (.txt), see below.

## Lab Modules

| # | Module | What you can explore |
|---|---|---|
| 01 | Atomic Structure | Element selection, shell models, atomic properties, and nucleus/electron visualization. |
| 02 | Hydrogen Spectrum | Bohr energy levels, electronic transitions, photon energy, and spectral lines. |
| 03 | Photoelectric Effect | Work function thresholds, emitted-electron kinetic energy, and intensity/frequency changes. |
| 04 | Radioactive Decay | Half-life, exponential decay, activity, and stochastic population behavior. |
| 05 | Particle Collisions | Elastic collisions, mass ratios, momentum, kinetic energy, and wall bounces. |
| 06 | Thermodynamics | Ideal-gas state variables and isothermal, isobaric, isochoric, and adiabatic processes. |
| 07 | Fluid Dynamics (Hydrodynamics) | 7 experiments: pipe flow & Venturi (continuity, Bernoulli, Reynolds), hydrostatics & buoyancy, Torricelli draining tank, Poiseuille flow (Q ∝ R⁴), potential flow past a cylinder with circulation and lift, sphere drag & terminal velocity, and dispersive surface waves with particle orbits. |
| 08 | Quantum Physics | 9 experiments: double slit, tunneling, entanglement, plus particle in a box (levels and superposition beating), harmonic oscillator (forbidden-region leakage, coherent state), wave-packet scattering (split-operator Schrödinger solver), spin-½ / qubit (Bloch sphere, gates, Stern–Gerlach chains), hydrogen orbitals, and a Mach–Zehnder interferometer with an Elitzur–Vaidman bomb tester. |
| 09 | Electromagnetism | Electric fields, magnetic fields, Lorentz force, and electromagnetic waves. |
| 10 | Optics | Lenses, mirrors, refraction, diffraction, and interference. |
| 11 | Real Analysis | ε–N limits of sequences, series convergence (ratio/root tests), ε–δ continuity, Riemann/Darboux integration, Taylor series with Lagrange remainder. **3D animations:** a 2-D Riemann sum as boxes that refine onto a typed surface f(x, y), and a Fourier/Gibbs surface of partial sums stacked over N. |
| 12 | Complex Analysis | Argand plane (products, powers, n-th roots), conformal mappings with f′(z) at a point, domain colouring, Mandelbrot and Julia sets. **3D animations:** |f(z)| landscapes of a typed function (poles, zeros, orbiting point with its image loop), Riemann surfaces of √z, ∛z and log z, and a Riemann sphere that morphs into the image of a Möbius/typed map. |
| 13 | Vector Spaces | Span, basis and Gram–Schmidt; linear maps and eigenvectors; gradient fields and directional derivatives; gradient descent with momentum; Laplace's equation solved by Jacobi / Gauss–Seidel / SOR / gradient descent on the Dirichlet energy. **3D animations:** streaming RK4 tracers in a typed field F(x, y, z) (Lorenz, Rössler, …) with ∇·F and ∇×F, a 3×3 matrix deforming the unit cube and sphere with eigenvectors, and a ball rolling down a 3D surface by gradient descent. |

## Exporting Results

Use **Record result** in any experiment, then open the Lab Notebook and choose:

- **Sheet (.csv)** — `quanta-lab-results_<YYYYMMDD-HHMMSS>.csv`. Always the same seven columns:
  `No., Date, Time, Module, Experiment, Setup, Result`. UTF-8 with BOM (Excel opens it correctly),
  CRLF line endings, RFC 4180 quoting, ISO dates (`YYYY-MM-DD`) and 24-hour times, so the file looks the same in every locale.
  Cells that start with `= + - @` are neutralised to prevent spreadsheet formula injection.
- **Report (.txt)** — `quanta-lab-report_<YYYYMMDD-HHMMSS>.txt`. A fixed 78-column layout: title block, session summary
  (modules visited, results recorded), then one numbered entry per result (module, experiment, setup, result), and a footer.

Both files are generated by `src/utils/exportReport.js`; with no recorded results the buttons are disabled and an empty export still contains the header row.

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Development

Start the Vite development server:

```bash
npm run dev
```

Open the local URL shown in your terminal, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
```

### Preview the Build

```bash
npm run preview
```

### 3D animations

The 3D labs (marked ◆ in each module) use a small dependency-free renderer, `src/components/math/Scene3D.jsx`: a perspective camera and depth-sorted, flat-shaded polygons on a 2-D canvas. Drag to orbit, scroll to zoom, double-click or *Reset view* to recentre, *Auto-spin* to toggle rotation (off by default when the OS asks for reduced motion).

### Typing your own equations

Complex Analysis (*Conformal mapping*, *Domain colouring*) and Vector Spaces (*Gradient field*, *Gradient descent*, and the new *Custom map* lab) accept a typed formula.
The parser (`src/math/expr.js`) is a safe tokenizer + Pratt parser — it never uses `eval`.

| Where | Variables | Example |
| --- | --- | --- |
| Complex maps `w = f(z)` | `z` (or `x`, `y`), `i`, `pi`, `e` | `(z^2+1)/(z-1)`, `exp(i*z)`, `sin(z)*cosh(z)`, `2z(z+1)` |
| Scalar functions `f(x, y)` | `x`, `y`, `pi`, `e` | `x^2 + 3*y^2 + sin(2*x)` |
| Vector maps `F = (P, Q)` | `x`, `y` | `P = y`, `Q = -sin(x) - 0.2*y` |

Operators `+ − * / ^` (with implicit multiplication such as `2x` and `2(x+1)`), functions `sin cos tan asin acos atan sinh cosh tanh exp ln log sqrt abs` (complex also `conj re im arg`), constants `pi`, `e`, `tau`. Mistakes are reported inline ("Unknown name 'q'", "Missing closing parenthesis") and the last valid formula stays on screen while you type. Derivatives and Jacobians are computed numerically, so every analytic check still works for your own formula.

### Tests

```bash
npm run test:math
```

Runs four suites with `tsx` (fetched on demand by `npx`): `tests/math.test.mjs` (complex identities, ε–N / series / Riemann / Taylor results against closed forms, eigenvectors, gradients against finite differences, descent convergence, Laplace solvers against the exact solution, linearisation and flow helpers), `tests/expr.test.mjs` (the formula parser) `tests/labs3d.test.mjs` (2-D Riemann sums, Gibbs overshoot, stereographic projection, branch surfaces, 3×3 eigen-decomposition, 3D RK4 and divergence/curl) and `tests/labs.test.mjs` (quantum and hydrodynamic physics: box and oscillator normalisation and energies, solver unitarity and uncertainty, Bloch-sphere gates and Stern–Gerlach 25 %, hydrogen radial normalisation and ⟨r⟩, Mach–Zehnder and bomb-tester probabilities, buoyancy, Torricelli, Poiseuille, Kutta–Joukowski lift, terminal velocity and wave dispersion).

### Linting

```bash
npm run lint
```

> Note: the project defines a lint script, but an ESLint configuration file may need to be added before the command can run successfully in a fresh checkout.

## Educational Notes
